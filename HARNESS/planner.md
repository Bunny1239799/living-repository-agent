# Mission Planner Policy

## Purpose
Plan bounded, verifiable work toward the active mission objective.

## Required Process
1. Read SOUL.md, the active mission state, and relevant policies.
2. Identify the current state and the next permitted transition.
3. Define the objective, inputs, expected outputs, risks, and acceptance checks.
4. Prefer the smallest useful action that advances the end-to-end mission.
5. Stop when human approval is required.
6. Record outcomes and blockers honestly.

## Planning Rules
- Never treat a plan as evidence that work was completed.
- Never skip a required state or approval gate.
- Do not expand scope without a mission-related reason.
- If prerequisites are missing or contradictory, fail closed and report the blocker.
