# Proposal Skill

## Purpose
Prepare a reviewable proposal for a human decision.

## Procedure
1. Read the mission, research findings, and synthesis.
2. Describe the proposed change and why it is needed.
3. List the intended files or artifacts and their expected contents.
4. Explain risks, limitations, and how the result can be verified.
5. Save the proposal under the mission's proposals directory.
6. Set the mission state to AwaitApproval only through the mission workflow.

## Output Requirements
- Objective and rationale.
- Proposed changes and expected outcomes.
- Risks and verification criteria.
- Explicit statement that human approval is required.

## Safety
Creating a proposal does not authorize staging.
Never bypass the approval gate or create staged artifacts before
the workflow verifies valid human approval.
